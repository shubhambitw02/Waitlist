How it works

One app. Two ways to use it.

Post what you need done, or turn on availability and start earning nearby. Switch between the two whenever you like.

  1. 1 Post what you need done. Describe the task, add a location, and set what you're paying — Barrtar checks it fits safe, lawful use before it goes live.
  2. 2 Choose now or schedule a time. Get help right away, or line it up for later today, tomorrow, or the day after.
  3. 3 Get matched with nearby help. Barrtar looks for available doers close to you first, then widens the search if needed.
  4. 4 Share the start code when work begins. Check that the person who arrived matches who Barrtar shows as accepted, then share the code to start the task.
  5. 5 Pay directly after completion. Settle up with the doer yourself — by UPI or cash — once the task is done.
  1. 1 Turn on Available for Work. Complete quick ID verification once, then you're ready to accept tasks.
  2. 2 Get nearby task alerts. With background alerts enabled, you can hear about tasks nearby even when the app is closed.
  3. 3 Accept tasks that fit your time and location. Browse or wait for alerts — you choose what's worth your time.
  4. 4 Use the start code to begin. The creator shares a start code once they've confirmed it's you — that's your signal to get going.
  5. 5 Complete the task and get paid directly. No platform fee — you keep what you earn.

Trust & safety

Built so both sides can trust the handoff.

Barrtar can't make every real-world interaction risk-free, but every task is backed by the same four checks.

Start-code protected tasks

Creators confirm the person who arrived matches the accepted doer before sharing the code that starts work.

Verification for doers

Anyone accepting and working on tasks completes ID verification first.

Direct payment tracking

Payments happen directly between users, with proof you can attach if support is ever needed.

Issue reporting & support

Report a problem or raise a dispute in the app, any time — Barrtar reviews the evidence from both sides.

Post tasks you need done — not ads for services you provide. Barrtar is a task marketplace, not a classifieds board. Read the community guidelines.
